# Aditi Malviya — UI/UX Engineer & Creative Technologist Portfolio

A production-grade, human-centered portfolio designed specifically for **Google UI/UX Engineer / Design Technologist** roles. Built with React 18, TypeScript, Tailwind CSS, Google Material Design 3 tokens, and Web Audio API synthesized haptics.

Inspired by:
- **[Dev Damilare](https://www.devdamilare.tech/#projects)**: Dynamic 3D perspective card tilt physics, cursor spotlight gradients, live interactive simulator environments inside project cards, and deep-dive UX case study drawers.
- **[Palak on Web](https://palakonweb.in/)**: Warm editorial aesthetics, playful personality, interactive animated SVG pet sanctuary (**Mochi the Cat**, **Bubu the Shiba Inu**, **Pip the Bird**), nap/wake states, yarn tosses, and retro-modern design badges.

---

## 🌟 Highlights & Features

### 1. Tailored for Google UI/UX Engineer Roles
- **Google Material Design 3 Live Token Playground**: An interactive control bar in the Hero section allowing hiring managers to tweak seed colors (`Google Blue`, `Google Green`, `Google Yellow`, `Google Red`, `Creative Violet`) and corner radius tokens (`4px Sharp` to `28px Pill`) in real time.
- **Google Component & Micro-Interactions Lab**:
  - Accessible fluid spring-physics switch (WCAG AA compliant, 60fps spring transitions).
  - Spatial haptic button computing cursor click coordinates with radial wavefront ripple.
  - Interactive layer elevation deck (Material surface elevation 1 to 3).
  - Live WCAG 2.1 AAA contrast and keyboard traversal audit checklist.
- **UX Case Study Deep Dive**: Every project features a structured breakdown: *The UX Challenge $\rightarrow$ Target Users $\rightarrow$ Design System Decisions $\rightarrow$ Technical Architecture $\rightarrow$ Measurable Impact*.

### 2. Live Interactive Simulators (Dev Damilare Style)
Inside each project card, visitors can interact with a functional simulator:
1. **Adaptive AI Test Generator & CBT Portal**:
   - Live LaTeX formula renderer toggle.
   - Real-time proctoring telemetry alert simulator (simulates alt-tab detection with non-intrusive amber warnings).
   - Instant sub-100ms Drizzle ORM query latency telemetry.
2. **AI-Adaptive Onboarding Engine** (*from `aditi-malviya666` GitHub repo*):
   - Interactive DAG skill graph visualizer with dependency unlocks and celebratory confetti.
3. **AgriVerse: Privacy-Preserving Plant Disease Platform**:
   - Decentralized Federated Learning node aggregation simulator with 98.7% accuracy metrics and zero-image leakage guarantee.
4. **Vision-First Autonomous Navigation HUD**:
   - Interactive heads-up display overlay with dynamic YOLOv8 bounding boxes, road segmentation lines, speed throttle slider, and predictive Time-to-Collision (TTC) alert gauge.
5. **StudifySuccess AI Mascot & Mobile Features** (*500K+ Learners*):
   - Interactive mascot companion dialog with emotional states (Happy, Thinking, Cheering).
6. **GSSoC Algorithmic Suite & Visualizer**:
   - Step-by-step Breadth-First-Search (BFS) memory model visualizer showcasing GeeksforGeeks FoT Institutional Rank #1 (Score: 853).

### 3. Palak-Inspired Delight: The Interactive Pet Sanctuary
- **Mochi the Calico Cat**: Purrs softly on hover, increments love hearts, reacts to yarn ball tosses.
- **Bubu the Shiba Inu**: Wags curly tail, catches dog treats, gives interactive high paws.
- **Pip the Origami Bird**: Flutters wings and sings synthesized 4-note musical chimes.
- **Nap Time / Wake Up mode**: Puts the entire garden to sleep with animated "Zzz" bubbles.
- **Web Audio API Synthesizer**: Zero external MP3 downloads; all clicks, pops, purrs, and chimes are dynamically synthesized.
